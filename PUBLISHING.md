# Checklist sebelum rilis

- [ ] Tambahkan file APK final dengan nama `animego.apk` di folder yang sama dengan `index.html`.
- [ ] Pastikan ukuran APK yang tampil di halaman sesuai berkas yang akan dirilis.
- [ ] Bila punya screenshot asli, ganti ilustrasi yang ada di `previews/`.
- [ ] Push isi website dan APK ke GitHub.
- [ ] Aktifkan GitHub Pages pada branch/folder yang benar.
- [ ] Tes tombol download dari URL GitHub Pages, lalu coba instal APK di perangkat target.

Jangan menuliskan nomor versi atau tanggal rilis yang belum benar-benar ditetapkan.
