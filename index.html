DIBUAT UNTUK MENONTON

Yang bikin AnimeGo praktis.

Fitur inti disusun supaya aktivitas menonton dan mengelola episode bisa dilakukan dari satu aplikasi.

Temukan anime melalui halaman beranda, kategori jelajah, pencarian, dan detail judul.

Catatan kompatibilitas

Manifest aplikasi menetapkan minSdkVersion 23, setara Android 6.0 Marshmallow. Tidak ada maxSdkVersion yang ditetapkan.

Ini bukan jaminan aplikasi pasti berjalan di seluruh versi Android yang lebih baru. Pengujian pada Android 13 dan versi setelahnya masih diperlukan.

PANDUAN SINGKAT

Cara memasang APK.

Langkah umum untuk memasang AnimeGo dari berkas APK.

01

Unduh file

Tekan tombol Download AnimeGo dan tunggu sampai berkas selesai diunduh.

02

Buka APK

Buka file animego.apk dari notifikasi unduhan atau aplikasi File Manager.

03

Izinkan pemasangan

Jika diminta, izinkan browser atau File Manager memasang aplikasi dari sumber ini, lalu lanjutkan instalasi.

TENTANG PROYEK

Dikembangkan sebagai proyek independen.

AnimeGo adalah aplikasi Android yang berfokus pada penjelajahan katalog anime, pemutaran video, riwayat, favorit, dan pengelolaan unduhan offline. Proyek ini dikembangkan dan dipublikasikan melalui akun GitHub reyhanaarch64.
